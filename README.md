# PERSONAL OS — One-click online APK build

This project is local-only: no Firebase, no login, no network permission. Data is stored in the Android WebView local storage.

## Build the APK online with GitHub
1. Create a GitHub account if needed.
2. Create a new repository.
3. Upload all files/folders from this project to the repository.
4. Open the **Actions** tab.
5. Select **Build Personal OS APK**.
6. Click **Run workflow**.
7. When it finishes, open the workflow run and download the **PersonalOS-APK** artifact.
8. Extract it and install `app-debug.apk` on your Android phone.

No Android Studio is required for this build path.
